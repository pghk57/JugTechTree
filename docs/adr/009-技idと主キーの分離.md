# 009-技idと主キーの分離
2026/11/13

## 状況（Status）
提案中

## 状況（Context）
- 技idをユーザーが意図してつける仕様にすると、技idにtypoがあった場合データの修正が非常に面倒になる
- このため技idを主キーにするか、技idとは別に主キーを決定する判断をする必要がある

## 決定（Decision）
- 技idと主キーは分離する

## 理由（Reasons）
- 技idはurlに含めたいが、typoがあった際の修正の手間を鑑み、主キーは別に取った方がよい

## 影響（Consequences）
- 人間が理解しやすい技idを保持したまま、データの修正が容易にできるようになった
