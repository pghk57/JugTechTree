# 004-解説の要件
2026/11/12

## 状況（Status）
承認

## 状況（Context）
- 技術木のノードに載せる解説の要件について、ADRに記録に残す
- このADRに記載される内容は2026/11/6に開催した説明会で部員に共有した内容およびその後部員から出た要望をまとめたものである
## 決定（Decision）
- 解説は「{ユーザー名}による解説」という題でユーザーごとに作成するものとする
    - ただし将来的には共著機能を実装する予定である
- 解説はMarkDown形式で書かれるものとする
    - htmlタグの埋め込みもできるようにする
## 理由
- 解説はJTTで統一できるものではない（個人差が大きい）と判断したため、個々が書くことに
- 共著機能は複数人で協力して解説を作成することが想定されるため
- htmlタグの埋め込みを実装することで、独自プレーヤーが使えるようにすることができる
## 影響（Consequences）
- ユーザー認証周りを考える必要が出てきた
- MarkDownの実装について考える必要も出てきた
- 動画を使えるようになったことで、動画の置き場所を考える必要も出てきた
