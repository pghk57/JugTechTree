# 006-サーバー構成
2026/11/13

## 状況（Status）
提案中

## 状況（Context）
- ADR005で解説動画を自前配信する方針を立てたことで、サーバー構成について検討する必要が出てきた

## 決定（Decision）
- サーバーは国内VPS1台に集約する

## 理由
- 部室のpcをサーバーにすることは、学内wi-fiの禁止事項に抵触するため不可能である
- バックエンドにはGoを採用する関係上、常駐プロセスが禁止されている共用サーバーの利用も難しい
- 解説動画をローカルに置くことも踏まえると、国内VPS1台に全て集約するのが運用上最も労力が少なく済むと判断した

## 影響（Consequences）
- 契約するサービスが一つだけに限定されるので、金銭面でも運用面でも管理が楽になると思われる
- サーバー構成が決定したことで、種々の設計ができるようになった
- サーバー管理を自分たちでする必要が発生する
- VPSのストレージが吹き飛ぶとデータも全て吹き飛ぶリスクを負うことになった
    - バックアップを取る仕組みを整える必要がある
