# 005-解説動画について
2026/11/12

## 状況（Status）
提案中

## 状況（Context）
- 解説に動画を載せられるようになり、解説動画の取り扱いやその周辺を決める必要が出てきた
## 決定（Decision）
- 基本的に動画は自前で配信することにする
- 仮の決定として、動画はサーバーのローカルに置くことにする
    - JTTの公開範囲を部内にとどめておく間は、短時間で切れるurlを発行して閲覧できるようにする
- 動画の再生には独自のプレーヤーを使えるようにする
- 独自プレーヤーは以下の機能を持つものとする
    - 低倍速再生（*0.1から0.1刻みで1まで）
    - コマ送り
    - 左右反転
    - 左右のオーバーレイ表示

## 理由
- youtubeに動画をアップロードするのが最も簡単で堅牢な方法ではあるが、それでは練習時に役立つ再生機能を実装できない（コマ送り、超低速再生など）ことから、この案は却下された
- 試算の結果、解説に使われる動画が1本30~60s程度で、解説がJTT全体で1000個作られるとしても、動画が占領するサイズは20~30GBに収まることがわかった。
    - 当面の間はサーバーのローカルに動画を置いても問題ないと思われる
## 影響（Consequences）
- 動画を自前配信にすることによって、動画を自由に扱えるようになった
- 独自プレーヤーを作ることによって、部員の要望に応えやすくなった
- 配信を自前にすることで、ストレージや公開範囲、閲覧urlの発行、プレーヤーの実装など自分たちで考えなければならないことが増えた
