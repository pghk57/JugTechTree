# 007-技術木の表示に用いるフレームワーク
2026/11/13

## 状況（Status）
提案中

## 状況（Context）
- 技術木の表示に使うライブラリ・フレームワークについて記録に残すためにADRを作成

## 決定（Decision）
- 技術木の表示にはvue flow + dagreを用いる

## 理由（Reasons）
- vueflow: フロントエンドのフレームワークにvueを用いる予定であるため
- dagre: モックで実験してみたとこr、elkjsに比べレイアウトが崩れにくかったため
    - [モック](https://claude.ai/artifact/KSHSeZYz3smHnR7j1mk8Mp)

## 影響（Consequences）
- dagreは設定できる項目が少ないため、考える要素を少なくできる
- dagreはelkjsに比べ自由度が低いため、将来的には別のライブラリへの乗り換えを検討する必要が生じるかもしれない
