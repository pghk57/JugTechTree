# JugTechTreeやりたいことリスト

- 技術木のツリー（DAG）表示
    - 技術木をツリー（DAG）形式で表示できる
    - ノードをクリックすると解説が表示される
    - ノードをクリックすると派生元、派生先の技がハイライトされる
    - ノードごとに習得済みかどうかをマークできる
    - あるノードに対応する技を習得するためのロードマップを、学習状況に応じて提示する
- 技術木の構築
    - 編集画面が存在し、そこではノードの追加ができる
    - 各ノードにおいて、自分の解説を追加することができる
    - 解説の作成を行うUIが存在する
    - 解説にはMarkdown記法を用いることができる
    - 解説の作成に他のユーザーを参加させることができる（共著）
