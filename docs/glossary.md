# JugTechTree用語集

| 用語 | 定義 |
| --- | --- |
| ユーザー | JTTの利用者全てを指す。ジャグリングにおける強さは関係ない。 |
| 学習者 | JTTの利用者であって、技の習得を目的として使う者。 |
| 技術木 | 各道具の技とその関係を、有向非巡回グラフ形式で表したデータ。 |
| 編集者 | ユーザーであって、JTTの技術木の構築に関与する者。 |
| 必須 | 技同士の関係であって、理論上終点の技の習得をする上では必要ないが、実質的には始点の技なしには習得が不可能であるという関係。 |
| 推奨 | 技同士の関係であって、始点の技を習得していると、終点の技の習得の効率が上がる関係。 |
| 関係 | 技同士の関係であって、習得には直接寄与しないものの、関連する技や参考になる技の関係。無向辺。 |
